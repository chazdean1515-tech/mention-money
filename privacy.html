Privacy

Mention Money is a static site hosted on GitHub Pages. We do not run accounts, and we do not set analytics cookies.

GitHub Pages serves the pages you request and may log technical data, such as an IP address, under GitHub's own policy.

The typeface is self-hosted on this site. Pages do not load Google Fonts.

If you follow a link to Kalshi or to X, that site has its own policy. The Kalshi link is a referral link, so Kalshi can tell that you arrived through Mention Money.

If you send SOL, the transaction is public on the Solana network. The address is the one shown in the support dialog. We do not ask for your name.

Questions go to @MentionMoneyHQ. There is no email address on this domain yet.
